# Integrity Analysis of Low-Level NLP Using Polynomial Rings

An individual academic project for the **Quiz 2 assessment of Algebra 2**, exploring text representation and data integrity through polynomial ring operations using Python.

## Objectives

- Encode text characters into numerical coefficient sequences and represent them as polynomials.
- Simulate polynomial multiplication using convolution over the integer polynomial ring.
- Investigate degree reduction under modular arithmetic and the effects of zero divisors.
- Explore polynomial deconvolution as a method for reconstructing the original coefficient sequence.

## Mathematical Concepts

- Polynomial Rings
- Polynomial Multiplication and Convolution
- Modular Arithmetic
- Zero Divisors
- Integral Domains
- Polynomial Division and Fraction Fields

## Experiments

1. **Polynomial Representation and Multiplication**  
   Transform text into coefficient sequences and perform polynomial multiplication over \(\mathbb{Z}[x]\).

2. **Modular Arithmetic and Degree Reduction**  
   Apply coefficient-wise modular reduction to examine changes in polynomial degree and investigate the role of zero divisors in \(\mathbb{Z}_n\).

3. **Polynomial Deconvolution and Data Recovery**  
   Use numerical polynomial division to reconstruct the original coefficient sequence and examine the recovery process.
